# drivefs

Google Drive, OneDrive Personal, SharePoint document library를 애플리케이션의
파일 저장소로 사용하는 Python 및 Node.js 라이브러리 프로젝트입니다.

현재 상태는 **v1.0.0 설계 확정, 구현 전**입니다. 공개 API와 지원 범위는
[개발 기획서](docs/v1-plan.md)와
[FileStorage API 명세](spec/storage-api.md)에 있습니다.
[기획 검토 기록](docs/v1-review.md)은 v1 범위 결정과 배포 전 검증 조건을
설명합니다.
